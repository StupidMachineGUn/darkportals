# Art Bundle Pack generator
Original procedural pixel art (no third-party assets). `python3 bake_client.py ../../client/artdata.js` regenerates the sheets embedded in the client.
Modules: terrain (24 biomes, liquids), chars (4-dir humanoids, armor tiers, weapons), mobs+catalog (79 mobs), items (129 icons), props (71 trees/buildings/decor), world (160x96 biome preview).
